💡 站长如何在 GitHub 上更新笔记与文件？

你的所有笔记与文件都存放在 GitHub 仓库中。任何人打开本站只能高速浏览、排版级预览和下载；只有你能登录你的 GitHub 账号添加或修改内容。

方式 1

📂 在 files/ 目录上传（小文件推荐）

进入项目仓库中的 files/ 文件夹：

  • 点击右上角 【Add file】->【Upload files】
  • 把 Word（.docx）、Excel（.xlsx）或小文件拖进去提交
  • 在 notes.json 中填写 "url": "files/文件名.docx"
方式 2 (强烈推荐)

🚀 在 GitHub Release 上传图片（不占代码体积）

进入仓库右侧的 【Releases】 页面：

  • 点击 【Draft a new release】，标签填 assets
  • 把高清图片、思维导图或大文件直接拖进附件框，点击发布
  • 在 notes.json 中只需填：
    {"name": "架构图.png", "release": "assets"}
    系统会自动解析为 Release 极速直链！单个文件支持高达 2GB！
登记笔记

✍️ 在 notes.json 中登记

在仓库根目录下打开 notes.json 点击 ✏️ 铅笔在线编辑：

{
  "id": "my-new-note",
  "title": "我的新笔记标题",
  "tags": ["学习笔记", "思维导图"],
  "date": "2026-11-12",
  "content": "这里是正文详细说明...",
  "images": [
    { "name": "思维导图.png", "release": "assets" }
  ],
  "files": [
    { "name": "复习手册.docx", "url": "files/复习手册.docx", "size": 32000 }
  ]
}

提交保存后，GitHub Pages 会在 30 秒内全网同步自动生效！
