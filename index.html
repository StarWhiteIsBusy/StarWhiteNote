💡 站长如何在 GitHub 上更新笔记与文件？

你的所有笔记与文件都存放在 GitHub 仓库中。任何人打开本站只能高速浏览、排版级预览和下载；只有你能登录你的 GitHub 账号添加或修改内容。

步骤 1

📂 在 GitHub 上传文件或图片

登录 github.com，进入你的项目仓库，点击进入 files/ 文件夹：

  • 点击右上角的 【Add file】->【Upload files】
  • 把你的 Word 文档（.docx）、Excel 表格（.xlsx）、高清图片或 PDF 拖进网页
  • 点击底部的绿色 【Commit changes】 提交保存
步骤 2

✍️ 在 notes.json 中登记笔记

在仓库根目录下点击打开 notes.json 文件，点击右上角的 ✏️ 铅笔图标进行在线编辑：

{
  "id": "my-new-note",
  "title": "我的新笔记标题",
  "tags": ["工作方案", "Word文档"],
  "date": "2026-11-12",
  "content": "这里是笔记的内容与详细说明文字...",
  "images": [
    { "name": "架构图.png", "url": "files/架构图.png", "size": 25000 }
  ],
  "files": [
    { "name": "设计手册.docx", "url": "files/设计手册.docx", "size": 32000 }
  ]
}

仿照上面的格式追加一条笔记即可。你填写的 tags 标签会自动出现在网站顶部的筛选栏中！

步骤 3

🚀 自动生效并全球秒开

提交保存后，GitHub Pages 会自动同步更新（通常 30 秒至 1 分钟）。

刷新你的网站，所有人就能立刻看到最新笔记，并享受在线 Word 完整排版预览与下载！
