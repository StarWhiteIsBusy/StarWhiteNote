# 复数

## 一、复数的基本概念
- 1. 复数的代数形式
  - 形式：z ＝ a + bi（a, b ∈ R）
  - 组成要素：
    - a 称为实部，记作 Re(z) ＝ a
    - b 称为虚部，记作 Im(z) ＝ b（注意：虚部是实数 b，不包含虚数单位 i）
    - i 为虚数单位，满足 i² ＝ -1
  - 分类讨论：
    - 当 b ＝ 0 时，z 为实数
    - 当 b ≠ 0 时，z 为虚数
    - 当 a ＝ 0 且 b ≠ 0 时，z 为纯虚数
- 2. 复数的几何意义
  - 复平面：以 x 轴为实轴，y 轴为虚轴建立的直角坐标系平面
  - 一一对应关系：
    - 复数 z ＝ a + bi ↔ 复平面内的点 Z(a, b)
    - 复数 z ＝ a + bi ↔ 平面向量 OZ ＝ (a, b)
- 3. 复数的模（绝对值）
  - 概念：向量 OZ 的长度，即点 Z(a, b) 到坐标原点的距离
  - 计算公式：|z| ＝ √(a² + b²)
  - 性质：|z| ≥ 0，且 |z| ＝ |-z| ＝ |z̄|
- 4. 共轭复数
  - 概念：实部相等，虚部互为相反数的两个复数互为共轭复数
  - 形式：若 z ＝ a + bi，则共轭复数 z̄ ＝ a - bi
  - 几何意义：在复平面内，共轭复数对应的点关于实轴（x 轴）对称
  - 重要性质：
    - z·z̄ ＝ a² + b² ＝ |z|²

## 二、复数的运算与解题思想
- 1. 虚数单位 i 的周期性
  - 四次幂循环规律：
    - i⁴ᵏ⁺¹ ＝ i
    - i⁴ᵏ⁺² ＝ -1
    - i⁴ᵏ⁺³ ＝ -i
    - i⁴ᵏ ＝ 1（k ∈ Z）
  - 重要推论：
    - 连续 4 个相继整数次幂之和恒等于 0，即 iⁿ + iⁿ⁺¹ + iⁿ⁺² + iⁿ⁺³ ＝ 0
- 2. 核心思想方法一：化虚为实
  - 思想内涵：复数问题化归为实数问题
  - 判定准则：
    - 复数相等的充要条件：a + bi ＝ c + di ↔ a ＝ c 且 b ＝ d（a, b, c, d ∈ R）
    - 实部分离法：设 z ＝ x + yi（x, y ∈ R），代入条件方程分离实部和虚部，转化为实数方程组求解
- 3. 核心思想方法二：数形结合
  - 思想内涵：注意利用复数的几何意义进行分析与转化
  - 典型应用：
    - |z - z₀| 表示复平面上两点 z 与 z₀ 之间的距离
    - 结合点到原点、两点间距离、圆的方程、中垂线轨迹等平面几何性质快速解题

## 三、复数的三角形式与乘除模长
- 1. 复数的三角形式
  - 形式：z ＝ r(cosθ + i·sinθ)（其中 r ＝ |z| ≥ 0 为模，θ 为辐角）
- 2. 复数乘除法的几何运算规律
  - 核心规律：模相乘除，辐角加减
  - 乘法：[r₁(cosθ₁ + i·sinθ₁)] · [r₂(cosθ₂ + i·sinθ₂)] ＝ r₁r₂[cos(θ₁ + θ₂) + i·sin(θ₁ + θ₂)]
  - 除法：[r₁(cosθ₁ + i·sinθ₁)] / [r₂(cosθ₂ + i·sinθ₂)] ＝ (r₁ / r₂)[cos(θ₁ - θ₂) + i·sin(θ₁ - θ₂)]
- 3. 复数乘除的模性质
  - 乘积的模：|z₁·z₂| ＝ |z₁|·|z₂|
  - 商的模：|z₁ / z₂| ＝ |z₁| / |z₂|（z₂ ≠ 0）
  - 幂的模：|zⁿ| ＝ |z|ⁿ（n ∈ N*）
