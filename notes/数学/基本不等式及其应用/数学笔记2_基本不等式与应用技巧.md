# 基本不等式与应用技巧

## 一、基本不等式链
- **前提条件**：a, b > 0（均为正数）
- **核心不等式链**：
  2/(1/a + 1/b) ≤ √(ab) ≤ (a + b)/2 ≤ √((a² + b²)/2)
  - 调和平均数 ≤ 几何平均数 ≤ 算术平均数 ≤ 平方平均数
- **取等条件**：当且仅当 a = b 时，等号成立

## 二、常用变形与推论
- **推论 (1)**：a + b ≥ 2√(ab)
- **推论 (2)**：2(a² + b²) ≥ (a + b)²
- **推论 (3)**：ab ≤ (a² + b²)/2 且 ab ≤ (a + b)²/4

## 三、常用解题方法
- **常数代换法（“1”的代换）**：已知常数条件时（如 x + y = 1），通过乘除常数配凑展开求最值
- **权方和不等式**：x²/a + y²/b ≥ (x + y)²/(a + b)（快速求解分式型极值）

## 四、使用基本不等式注意事项

### 1. 核心六字口诀
- **一正**：各项必须均为正数
- **二定**：和为定值或积为定值
- **三取等**：等号成立的条件必须能取到

### 2. 三大解题要点
- **要点 1（配凑法）**：当不能直接使用基本不等式时，需先进行恒等变形、裂项或配凑系数
- **要点 2（取等一致性）**：多次（连续）使用基本不等式时，必须检验各步取等条件是否一致
- **要点 3（实数取等分析）**：
  - ① 由 (a - b)² ≥ 0 得：a² + b² ≥ 2ab，当且仅当 a = b 时取等
  - ② 由 (a + b)² ≥ 0 得：a² + b² ≥ -2ab，当且仅当 a = -b 时取等
