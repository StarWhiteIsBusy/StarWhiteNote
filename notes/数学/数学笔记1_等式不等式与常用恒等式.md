# 等式与不等式性质、证明方法与常用恒等式

## 一、实数大小关系的基本事实
- a > b ⇔ a - b > 0
- a = b ⇔ a - b = 0
- a < b ⇔ a - b < 0

## 二、等式的性质
- **性质①（对称性）**：如果 a = b，则 b = a
- **性质②（传递性）**：如果 a = b, b = c，则 a = c
- **性质③（加减运算）**：如果 a = b，则 a ± c = b ± c
- **性质④（乘法运算）**：如果 a = b，则 ac = bc
- **性质⑤（除法运算）**：如果 a = b 且 c ≠ 0，则 a/c = b/c

## 三、不等式的性质
- **性质①（对称性）**：a > b ⇔ b < a
- **性质②（传递性）**：a > b, b > c ⇒ a > c
- **性质③（可加性）**：a > b ⇒ a + c > b + c
- **性质④（乘负变号）**：a > b, c < 0 ⇒ ac < bc
- **性质⑤（同向可加）**：a > b, c > d ⇒ a + c > b + d

## 四、常用证明方法
- **综合法（由因导果）**：p ⇒ q ⇒ ...
  - 从已知条件出发，经逐步推导得出结论
- **分析法（执果索因）**：要证明……，只需证……
  - 从结论出发，逆向寻找使结论成立的充分条件
- **反证法**：
  - 步骤 1：先假设否定的结论成立
  - 步骤 2：由此进行推理得到矛盾
  - 步骤 3：从而得出原结论成立（假设不成立）

## 五、常用恒等式

### 1. 平方公式
- **完全平方和**：(a + b)² = a² + 2ab + b²
- **完全平方差**：(a - b)² = a² - 2ab + b²
- **平方差公式**：a² - b² = (a + b)(a - b)
- **三数和平方（★重点）**：(a + b + c)² = a² + b² + c² + 2ab + 2bc + 2ca

### 2. 立方公式
- **完全立方和**：(a + b)³ = a³ + 3a²b + 3ab² + b³
- **完全立方差**：(a - b)³ = a³ - 3a²b + 3ab² - b³
- **立方和公式**：a³ + b³ = (a + b)(a² - ab + b²)
- **立方差公式**：a³ - b³ = (a - b)(a² + ab + b²)
