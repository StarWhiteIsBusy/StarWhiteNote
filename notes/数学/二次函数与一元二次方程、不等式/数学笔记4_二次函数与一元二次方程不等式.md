# 二次函数与一元二次方程、不等式

## 一、二次函数

### 1. 基本定义与图象
- **标准形式**：f(x) = ax² + bx + c（其中 a ≠ 0）
- **图象特征**：图象为抛物线
- **顶点坐标**：(-b/(2a), (4ac - b²)/(4a))
- **对称轴方程**：x = -b/(2a)

### 2. 三大常用解析式
- **一般式**：y = ax² + bx + c
- **顶点式**：y = a(x + m)² + k
- **两根式（交点式）**：y = a(x - x₁)(x - x₂)（前提条件：判别式 Δ = b² - 4ac ≥ 0）

### 3. 函数重要性质
- **奇偶性**：当且仅当 b = 0 时，f(x) = ax² + c 为偶函数（图象关于 y 轴对称）

## 二、一元二次方程

### 1. 标准形式与配方推导
- **方程形式**：ax² + bx + c = 0（其中 a ≠ 0）
- **配方推导过程**：
  - ax² + bx + c = 0
  - ⇔ x² + (b/a)x + c/a = 0
  - ⇔ (x + b/(2a))² = (b² - 4ac) / (4a²)

### 2. 根的判别式 Δ 与解集
- **判别式定义**：Δ = b² - 4ac
- **情况 1（Δ < 0）**：无实数解，解集为 ∅（空集）
- **情况 2（Δ = 0）**：有两个相等的实数根，解集为 {-b/(2a)}
- **情况 3（Δ > 0）**：有两个不相等的实数根，解集为 {(-b + √Δ)/(2a), (-b - √Δ)/(2a)}

### 3. 根与系数的关系（韦达定理）
- **前提条件**：Δ ≥ 0，设两根为 x₁, x₂
- **两根之和**：x₁ + x₂ = -b/a
- **两根之积**：x₁ · x₂ = c/a

## 三、一元二次不等式

### 1. 常用解法步骤
- **因式分解法**：十字相乘或提取公因式
- **判别式定根法**：计算 Δ 判断抛物线与 x 轴交点个数
- **求根公式法**：直接求出零点后画出草图确定区间

### 2. 解集类型与特殊情况
- **常规解集**（以 a > 0 为例）：
  - 大于 0 取两边：x < x₁ 或 x > x₂
  - 小于 0 取中间：x₁ < x < x₂
- **特殊解集**：
  - 解集可能为 **∅（空集，无解）**
  - 解集可能为 **R（全体实数，恒成立）**
