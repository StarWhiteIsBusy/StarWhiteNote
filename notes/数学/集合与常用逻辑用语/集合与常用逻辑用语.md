# 集合与常用逻辑用语

## 一、集合的基本概念与表示
- **元素与集合的关系**：属于（∈）与不属于（∉）
- **集合中元素的特征**：确定性、互异性、无序性
- **常见数集**：自然数集 N、正整数集 N*、整数集 Z、有理数集 Q、实数集 R

## 二、集合间的基本关系
- **子集**：对任意 x ∈ A，都有 x ∈ B，则 A ⊆ B
- **真子集**：A ⊆ B 且存在 x ∈ B 但 x ∉ A，记作 A ⊊ B
- **集合相等**：若 A ⊆ B 且 B ⊆ A，则 A = B
- **空集**：不含任何元素的集合，记作 ∅，空集是任何集合的子集（∅ ⊆ A）

## 三、集合的基本运算
- **并集**：A ∪ B = {x | x ∈ A 或 x ∈ B}
- **交集**：A ∩ B = {x | x ∈ A 且 x ∈ B}
- **补集**：∁_U A = {x | x ∈ U 且 x ∉ A}

## 四、充分条件与必要条件
- **充分条件**：若 p ⇒ q，则 p 是 q 的充分条件
- **必要条件**：若 p ⇒ q，则 q 是 p 的必要条件
- **充要条件**：若 p ⇔ q，则 p 是 q 的充要条件
