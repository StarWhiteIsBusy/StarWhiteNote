# 绝对值不等式与函数

## 一、绝对值不等式

### 1. 实数绝对值的定义与推论
- **几何定义**：数轴上表示数 a 的点到原点的距离，记作 |a|
- **代数定义**：
  - 当 a > 0 时：|a| = a
  - 当 a = 0 时：|a| = 0
  - 当 a < 0 时：|a| = -a
- **核心推论**：
  - |a| ≥ a（当且仅当 a ≥ 0 时等号成立）
  - |a| ≥ -a（当且仅当 a ≤ 0 时等号成立）
  - |a| · |b| = |a · b|
  - |a| = |b| ⇔ a² = b²

### 2. 基本绝对值不等式解集（大于取两边，小于取中间）
- **大于型**：|x| > 2 ⇔ x < -2 或 x > 2
  - 解集区间：(-∞, -2) ∪ (2, +∞)
- **小于型**：|x| ≤ 2 ⇔ -2 ≤ x ≤ 2
  - 解集区间：[-2, 2]

### 3. 常见变形解法示例
- **示例 1（大于型）**：|x - 3| > 2 ⇔ x - 3 < -2 或 x - 3 > 2 ⇒ x < 1 或 x > 5
  - 解集区间：(-∞, 1) ∪ (5, +∞)
- **示例 2（小于型）**：|2x - 3| < 1 ⇔ -1 < 2x - 3 < 1 ⇒ 2 < 2x < 4 ⇒ 1 < x < 2
  - 解集区间：(1, 2)

## 二、绝对值函数

### 1. 分段法（分类讨论去绝对值）
- **基本形式**：f(x) = |x|
  - 当 x ≥ 0 时：f(x) = x
  - 当 x < 0 时：f(x) = -x

### 2. 整体翻折法则
- **解析式**：y = |f(x)|
  - 当 f(x) ≥ 0 时：y = f(x)
  - 当 f(x) < 0 时：y = -f(x)
- **图象变换规律**：保留 x 轴上方的图象，将 x 轴下方的图象沿 x 轴对称翻折到上方
- **典型范例**：y = |x² - 1|

## 三、绝对值三角不等式及其推广
- **核心不等式链**：
  ||a| - |b|| ≤ |a ± b| ≤ |a| + |b| ≤ √(2(a² + b²))

## 四、拓展模型（锅形模型）

### 1. 尖底锅模型（奇数个绝对值相加）
- **函数形式**：f(x) = |x - 1| + |x - 2| + ... + |x - (2n - 1)|（n 为正整数）
- **极值特征**：在正中间奇数项 x = n 处取得唯一的最小值
- **值域**：[f(n), +∞)

### 2. 平底锅模型（偶数个绝对值相加）
- **函数形式**：g(x) = |x - 1| + |x - 2| + ... + |x - 2n|（n 为正整数）
- **极值特征**：在中间区间 [n, n+1] 上的所有点均取得最小值
- **值域**：[g(n), +∞)

### 3. 歪底锅模型（带系数的绝对值相加）
- **函数形式**：f(x) = k₁|x - x₁| + k₂|x - x₂|（x₁ < x₂，且 k₁, k₂ > 0）
- **核心结论**：f(x)min = min{ f(x₁), f(x₂) }（最小值必定在权重较大的零点处取得）
- **判定细则**：
  - 当 k₁ > k₂ > 0 时：f(x)min = f(x₁)
  - 当 k₂ > k₁ > 0 时：f(x)min = f(x₂)

## 五、实战技巧与口算方法

### 1. 折线图象快速绘制口诀
- **1 绝 2 段 3 个点**：含有 1 个绝对值符号，图象分为 2 段，描出 3 个特征点（零点及两侧各一点）即可连线
- **2 绝 3 段 4 个点**：含有 2 个绝对值符号，图象分为 3 段，描出 4 个特征点（两个零点及两侧各一点）即可连线

### 2. 函数 f(x) = a|x - x₁| + b|x - x₂| 极值与值域口算方法

#### ① 当 |a| = |b| 时（系数绝对值相等）
- **口算思路**：直接利用三角不等式转化
- **例 1（加法求最值）**：y = |x - 1| + |x - 2| ≥ |(x - 1) - (x - 2)| = 1
  - 值域为：[1, +∞)
- **例 2（减法求最值）**：y = |x - 1| - |x - 2| ⇒ |y| ≤ |(x - 1) - (x - 2)| = 1
  - 即 -1 ≤ y ≤ 1，值域为：[-1, 1]

#### ② 当 |a| ≠ |b| 时（系数绝对值不相等）
- **核心口诀：“看无穷，代零点”**（聚焦权重绝对值最大的项）：
- **例 1（权重为正）**：y = 2|x - 1| + 3|x - 2|
  - +3 权重最大且为正，故函数值可达到 +∞
  - 代入零点 x = 2 算得最小值 f(2) = 2
  - 值域为：[2, +∞)
- **例 2（权重为负）**：y = 2|x - 1| - 3|x - 2|
  - -3 权重最大且为负，故函数值可达到 -∞
  - 代入零点 x = 2 算得最大值 f(2) = 2
  - 值域为：(-∞, 2]
