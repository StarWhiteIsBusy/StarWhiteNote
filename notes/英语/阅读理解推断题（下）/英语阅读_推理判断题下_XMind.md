# 

## 一、写作意图题常见信号词
- purpose, intend to, aim to, want to, in order to

## 二、解题策略
- 1. 推断写作意图 / 目的：
  - ① 主旨推断法：根据文章或段落**主旨**推断作者的写作目的
  - ② 文体推断法：
    - 议论文：说服读者接受某个观点（1个观点）
    - 说明文：介绍某一事物
    - 记叙文：讲述故事或分享经历，表达感悟
    - 广告应用文：推销产品、服务，吸引顾客
    - 新闻：to inform / report
- 2. 判断文章出处：
  - 题干设置：be from, come from, be taken, appear
  - 干扰选项：paper, novel, text book
- 3. 推断观点态度：
  - 解题关键：明确“问谁”，以及“对什么事”
- 4. 推测下一段内容：
  - 寻找线索：重点关注最后一段反复提及的名词
