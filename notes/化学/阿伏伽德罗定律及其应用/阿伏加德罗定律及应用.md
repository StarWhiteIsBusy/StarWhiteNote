## 一、阿伏加德罗定律及推论
- 1. 阿伏加德罗定律内容
  - 概念表述
    - 在相同的温度和压强下，相同体积的任何气体，含有相同数目的粒子（或气体的物质的量相同）
  - 口诀总结
    - “三同”定“一同”：同温、同压、同体积的任何气体具有相同的分子数
- 2. 定律与理想气体状态方程
  - 状态方程表达式
    - pV ＝ nRT
  - 各物理量含义
    - p：压强
    - V：气体体积
    - n：物质的量
    - R：气体常数
    - T：开尔文绝对温度（T ＝ 273 + t）
- 3. 重要推论公式
  - 质量与摩尔质量关系式
    - pV ＝ (m / M)RT
  - 密度与摩尔质量关系式
    - pM ＝ ρRT
- 4. 知识要点与解题技巧
  - (1) 记忆方法
    - 三正比，二反比，一连比
  - (2) 推论推导
    - 应用阿伏加德罗定律中的推论时，均可通过核心公式 pV ＝ nRT 快速导出
  - (3) 适用对象
    - 既适用于单一气体，也适用于混合气体
    - **特别注意：固体、液体不适用**
  - (4) “四同”制约关系
    - 同温、同压、同体积、同分子数相互依存制约
    - 只要“三同”成立，则“第四同”必定成立
  - (5) 密度与温度关系
    - 同种气体（M 相同）、压强 p 相同时，密度 ρ 和温度 T 成反比关系

## 二、阿伏加德罗常数（Nₐ）应用的解题技巧
- 技巧一：（气体）一审，二看
  - 审题要诀
    - 一审是否为气体
    - 二看“气体”是否存在于标准状况（0 ℃，101 kPa）下
  - 标况下非气体物质陷阱（常考物质）
    - 水（H₂O）：标况下为冰水混合物（固/液态）
    - 三氧化硫（SO₃）：标况下为固态
    - 含碳较多的有机物：四氯化碳（CCl₄）、氯仿（CHCl₃）、苯、戊烷等（C₅ 及以上烃）
- 技巧二：巧记特殊组成
  - 1. 微粒数目计算
    - 质子数、中子数、电子数计算（如：¹⁸O 与 ¹⁶O、D₂O、OH⁻ 等）
  - 2. 最简式相同的物质
    - NO₂ 与 N₂O₄（最简式均为 NO₂，同质量时所含原子数相同）
    - C₂H₄ 与 C₃H₆（最简式均为 CH₂，同质量时所含 C、H 原子数及共价键数相同）
  - 3. 常见物质所含化学键数目
    - 白磷（P₄）：1 mol P₄ 含有 6 mol P-P 键
    - 金刚石：1 mol 碳原子形成 2 mol C-C 键
    - 二氧化硅（SiO₂）：1 mol SiO₂ 含有 4 mol Si-O 键
    - 烷烃（CₙH₂ₙ₊₂）：1 mol 烷烃分子中含有 (3n + 1) mol 共价键
- 技巧三：（电离，水解）慧眼识别“弱粒子”
  - 1. 规避弱酸弱碱（不完全电离）
    - 牢记“六大强酸”（完全电离）：HCl、H₂SO₄、HNO₃、HBr、HI、HClO₄
    - 牢记“四大强碱”（完全电离）：阳离子为 K⁺、Na⁺、Ba²⁺、Ca²⁺（即 KOH、NaOH、Ba(OH)₂、Ca(OH)₂）
    - 其余酸碱多为弱电解质，部分电离，离子数远少于分子数
  - 2. 警惕弱电解质离子发生水解
    - 弱酸根阴离子（如 CO₃²⁻、CH₃COO⁻、S²⁻ 等）会水解，离子数减少
    - 弱碱阳离子（如 Fe³⁺、Al³⁺、NH₄⁺、Cu²⁺ 等）会水解，离子数减少
- 技巧四：（氧化还原）电子转移乾坤大挪移
  - 1. 同一物质在不同反应中的角色
    - 明确是作氧化剂、还原剂，还是歧化/自身氧化还原（如 Cl₂ 与碱反应、Na₂O₂ 与水/CO₂ 反应转移电子数）
  - 2. 反应物过量、少量要分清
    - 明确反应产物中变价元素的价态（如 Fe 与过量/少量稀硝酸反应分别生成 Fe²⁺ 或 Fe³⁺）
- 技巧五：揪出隐藏反应
  - 1. 可逆反应（不能进行到底，转化率小于 100%）
    - 2SO₂ + O₂ ⇌(催化剂/△) 2SO₃
    - 2NO₂ ⇌ N₂O₄
    - N₂ + 3H₂ ⇌(催化剂/高温高压) 2NH₃
    - Cl₂ + H₂O ⇌ HClO + HCl
  - 2. 浓度变化导致反应停止或产物改变
    - MnO₂ + 4HCl(浓) ＝(△) MnCl₂ + Cl₂↑ + 2H₂O（随着反应进行，浓盐酸变稀，稀盐酸与 MnO₂ 不反应）
    - Cu + 2H₂SO₄(浓) ＝(△) CuSO₄ + SO₂↑ + 2H₂O（随着反应进行，浓硫酸变稀，稀硫酸与 Cu 不反应）
    - Cu + 4HNO₃(浓) ＝ Cu(NO₃)₂ + 2NO₂↑ + 2H₂O（随着反应进行，浓硝酸变稀，继续与 Cu 反应生成 NO：3Cu + 8HNO₃(稀) ＝ 3Cu(NO₃)₂ + 2NO↑ + 4H₂O）
