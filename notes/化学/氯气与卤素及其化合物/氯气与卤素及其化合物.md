## 一、氯气的实验室制备与工业制法
- 1. 实验室制备原理
  - 氧化剂选择
    - 通常用强氧化剂（MnO₂、KMnO₄、K₂Cr₂O₇、KClO₃、Ca(ClO)₂ 等）氧化浓盐酸制取氯气
  - 典型反应原理
    - 用 MnO₂ 制取（需加热）：
      - MnO₂ + 4HCl(浓) ＝(△) MnCl₂ + Cl₂↑ + 2H₂O
    - 其他制备原理（无需加热）：
      - 重铬酸钾反应：14HCl(浓) + K₂Cr₂O₇ ＝ 2KCl + 2CrCl₃ + 7H₂O + 3Cl₂↑
      - 高锰酸钾反应：16HCl(浓) + 2KMnO₄ ＝ 2KCl + 2MnCl₂ + 8H₂O + 5Cl₂↑
      - 氯酸钾反应：6HCl(浓) + KClO₃ ＝ KCl + 3H₂O + 3Cl₂↑
      - 漂白粉反应：4HCl(浓) + Ca(ClO)₂ ＝ CaCl₂ + 2Cl₂↑ + 2H₂O
- 2. 实验注意事项与装置要点
  - (1) 装置类型
    - 固 + 液加热制气装置
  - (2) 反应物浓度要求
    - 必须使用浓盐酸，稀盐酸不行；随着反应进行浓盐酸变稀，反应会自动停止
  - (3) 加液仪器选择
    - 滴加浓盐酸使用分液漏斗（便于控制滴加速度与反应速率）；长颈漏斗容易漏气
  - (4) 净化与干燥
    - 饱和食盐水：吸收除去 Cl₂ 中混有的 HCl 气体（降低 Cl₂ 溶解度）
    - 浓硫酸：干燥 Cl₂
    - 干燥禁忌：浓 H₂SO₄ 不能干燥碱性气体（如 NH₃）和还原性气体（如 H₂S、HBr、HI）
  - (5) 尾气处理
    - 吸收剂：常用 NaOH 溶液吸收尾气
      - 反应方程式：2NaOH + Cl₂ ＝ NaCl + NaClO + H₂O
    - 禁忌：不能用澄清石灰水吸收尾气，因 Ca(OH)₂ 溶解度太小，吸收不完全
  - (6) 验满方法
    - 湿润的淀粉-KI 试纸置于瓶口，若试纸变蓝则集满（或湿润的蓝色石蕊试纸，先变红后褪色）
- 3. 拓展：工业制法（氯碱工业）
  - 反应原理：电解饱和食盐水
  - 反应方程式：2NaCl + 2H₂O ＝(通电) 2NaOH + Cl₂↑ + H₂↑

## 二、卤素单质及其化合物性质
- 1. 单质物理性质与颜色
  - 溴单质（Br₂）
    - 常温下为深红棕色液体（唯一液态非金属单质），易挥发，剧毒
    - 水中溶解呈橙黄色，有机溶剂中呈橙红色
  - 碘单质（I₂）
    - 紫黑色固体，易升华
    - 水中微溶呈黄色/淡黄色，有机溶剂中呈紫红色；特性：遇淀粉溶液变蓝
- 2. 卤素单质的相似性
  - (1) 与大多数金属反应
    - Br₂ 氧化性强：与 Fe 反应生成 FeBr₃
    - I₂ 氧化性较弱：与 Fe 反应只能生成 FeI₂
  - (2) 与氢气反应
    - 通式：X₂ + H₂ ＝(一定条件) 2HX（X 为 Cl、Br、I）
  - (3) 与水反应
    - 通式：X₂ + H₂O ⇌ HX + HXO（X 为 Cl、Br、I）
  - (4) 与强碱溶液反应
    - 通式：X₂ + 2NaOH ＝ NaX + NaXO + H₂O（X 为 Cl、Br、I）
- 3. 卤素及其化合物的特殊性
  - (1) 氟（F）
    - 无正化合价，非金属性最强，氧化性最强
    - 与水发生剧烈置换反应：2F₂ + 2H₂O ＝ 4HF + O₂（故 F₂ 不能置换出水溶液中的其他卤素单质）
    - 氢氟酸（HF）：弱酸，能腐蚀玻璃（4HF + SiO₂ ＝ SiF₄↑ + 2H₂O），必须保存在塑料瓶中
  - (2) 溴（Br）
    - 常温下唯一的液态非金属单质，易挥发有剧毒，保存需加水液封
    - 强腐蚀性，保存时不可使用橡胶塞
  - (3) 碘（I）
    - 加热易升华，遇淀粉变蓝，易溶于有机溶剂
    - 与 Na₂S₂O₃ 发生定量氧化还原反应：I₂ + 2S₂O₃²⁻ ＝ 2I⁻ + S₄O₆²⁻（常用于滴定分析法）
  - (4) 卤化银（AgX）
    - 溶解性：AgF 易溶于水；AgCl（白色）、AgBr（淡黄色）、AgI（黄色）难溶于水和稀硝酸
    - 感光性：AgBr、AgI 见光易分解，常用作感光材料；AgI 还用于人工降雨
  - (5) 卤化氢（HX）
    - 热稳定性：HF ＞ HCl ＞ HBr ＞ HI
    - 还原性：HF ＜ HCl ＜ HBr ＜ HI
    - 水溶液酸性：HF ＜ HCl ＜ HBr ＜ HI（HF 为弱酸，其余均为强酸）
  - (6) 卤素阴离子的还原性
    - 离子还原性强弱：F⁻ ＜ Cl⁻ ＜ Br⁻ ＜ I⁻
    - I⁻ 还原性很强，易被 Fe³⁺、HNO₃、MnO₄⁻(H⁺)、H₂O₂、O₂、ClO⁻、ClO₃⁻ 等强氧化剂氧化为 I₂
  - (7) 次卤酸及次卤酸盐
    - 均具有强氧化性和漂白性

## 三、卤素离子的检验方法
- 1. 沉淀法（AgNO₃ 溶液法）
  - 检验试剂：AgNO₃ 溶液 + 稀硝酸（排除 CO₃²⁻、SO₃²⁻ 等干扰）
  - 现象与结论：
    - 生成白色沉淀（AgCl）：含有 Cl⁻
    - 生成淡黄色沉淀（AgBr）：含有 Br⁻
    - 生成黄色沉淀（AgI）：含有 I⁻
- 2. 氧化-萃取法（置换萃取法）
  - 操作步骤：向未知溶液中加入氯水（或双氧水）氧化，再加入 CCl₄（下层）或苯/汽油（上层），充分振荡、静置分层
  - 现象与结论：
    - 有机层呈橙红或橙黄色：含有 Br⁻
    - 有机层呈紫红或紫红色：含有 I⁻
- 3. 氧化-淀粉检验法（专用于检验 I⁻）
  - 操作步骤：向未知液中加入新制氯水（或双氧水），振荡，再滴加淀粉溶液
  - 现象与结论：
    - 溶液变蓝：证明原溶液中含有 I⁻
