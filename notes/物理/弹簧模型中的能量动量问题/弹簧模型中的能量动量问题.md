# 弹簧模型中的能量动量问题

## 一、四个关键特征状态演化分析
- 状态 ①：初始状态（原长 l₀）
  - 物理情境：两物体质量分别为 m₁、m₂；m₁ 以初速度 v₀ 冲向静止的 m₂（v₂ ＝ 0），弹簧处于原长 l₀
  - 受力与加速度：弹簧未发生形变，两物块加速度均为 0
- 状态 ②：压缩到最短（l_min，弹性势能达最大值）
  - 运动特征：两物块达到共同速度（v₁ ＝ v₂ ＝ v_共），此时两物块相对静止，距离最近
  - 能量特征：系统动能损失最多，全部转化为弹簧的弹性势能，弹性势能达最大值（Eₚ max）
  - 加速度特征：弹簧压缩量最大，两物块所受弹力最大，加速度均达反向最大值
- 状态 ③：再次恢复原长（l₀，类完全弹性碰撞）
  - 运动特征：弹簧恢复原长 l₀，相互作用阶段性结束，m₁ 的速度变为 v₁₁，m₂ 的速度变为 v₂₁
  - 能量特征：弹性势能完全释放，系统机械能全部重新转化为两物块的动能，全过程等效于发生了一次**完全弹性碰撞**
- 状态 ④：拉伸到最长（l_max，弹性势能再次达最大值）
  - 运动特征：两物块速度再次相等（v₁ ＝ v₂ ＝ v_共），此时相对静止，距离最远
  - 能量特征：系统动能再次降至最小，弹簧拉伸量最大，弹性势能再次达到最大值（Eₚ max）

## 二、共速极值规律与公式推导
- 1. 动量守恒求共速
  - 系统不受外力，总动量守恒：
    - m₁v₀ ＝ (m₁ + m₂)v_共
    - 共同速度：v_共 ＝ m₁v₀ / (m₁ + m₂)
- 2. 机械能守恒求最大弹性势能
  - 系统机械能守恒（初动能 ＝ 共速动能 + 最大势能）：
    - (1/2)m₁v₀² ＝ (1/2)(m₁ + m₂)v_共² + Eₚ max
- 3. 最大弹性势能极简推论（相对动能公式）
  - 结论公式：
    - Eₚ max ＝ (1/2) · [m₁m₂ / (m₁ + m₂)] · (v₀ - 0)²
  - 物理意义：
    - 系统初末动能之差只与两物体初速度差（相对速度 Δv）和约化质量 μ ＝ m₁m₂ / (m₁ + m₂) 有关

## 三、类弹性碰撞规律（恢复原长状态 ③）
- 1. 质量大小与末速度特征
  - 若 m₁ ＝ m₂：速度完全交换
    - v₁₁ ＝ 0，v₂₁ ＝ v₀
  - 若 m₁ ＞ m₂：两物体同向向前运动
    - v₁₁ ＞ 0，v₂₁ ＞ 0
  - 若 m₁ ＜ m₂：m₁ 被反向弹回
    - v₁₁ ＜ 0，v₂₁ ＞ 0
- 2. 速度关于共速的对称性关系（相对速度守恒）
  - 对称关系等式：
    - v₁ - v_共 ＝ v_共 - v₁₁（碰前相对速度大小等于碰后相对速度大小）
    - v_共 - 0 ＝ v₂₁ - v_共（m₂ 的末速度满足：v₂₁ ＝ 2v_共）

## 四、v-t 图象分析与位移关系文字解析
- 1. v-t 图象特征解析（文字表述）
  - m₁ 的速度图线：初速度为 v₁，随时间沿正弦曲线减速至 v_共（状态 ②），再继续减速至 v₁₁（状态 ③），然后反向回升，具有周期性振动特征
  - m₂ 的速度图线：初速度为 0，随时间沿正弦曲线加速至 v_共（状态 ②），再继续加速至最大速度 v₂₁（状态 ③）
- 2. 图线与面积的物理意义
  - v-t 图线与时间轴所围的“面积”代表该物块在该时间段内通过的位移
  - 阴影面积（m₁ 与 m₂ 图线之间的面积差）即为弹簧的形变量（相对位移）：
    - Δx ＝ s₁ - s₂ ＝ l₀ - l_min
- 3. 位移与质量反比制约关系（人船模型推论）
  - 关系式：m₁s₁ ＝ m₂s₂
  - 物理内涵：在系统动量守恒且初动量可化简为质心系分析时，两物块位移之比与质量成反比（质量越大，移动距离越小）
